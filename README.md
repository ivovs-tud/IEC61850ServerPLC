# WFServer
------------------------

PLC structured text project implementing IEC614200-25 servers and interfaces for any number of wind turbines for use in the [HackAWindFarm](https://github.com/ivovs-tud/HackAWindFarm) Hackathon. Intended to run in tandem with a real-time wind farm simulation (https://github.com/ivovs-tud/RTS_WFC) and a IEC61400-25 client operated by a supervisory level wind farm controller (https://github.com/ivovs-tud/IEC61850SupervisoryController). 

This repository has been developed as part of the EU Horizon program [SUDOCO](https://sudoco.eu/).
